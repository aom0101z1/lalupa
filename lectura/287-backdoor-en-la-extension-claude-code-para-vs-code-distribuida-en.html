Backdoor en la extensión Claude Code para VS Code distribuida en Cursor Marketplace

30 de octubre de 2026 · Lectura de 4 min · Resumen en español de un artículo en inglés

Investigadores de seguridad descubrieron que una versión de la extensión Claude Code para Visual Studio Code, distribuida a través del Cursor Marketplace, contenía una puerta trasera que permitía ejecución remota de código. El hallazgo tuvo enorme repercusión en la comunidad de desarrolladores y llevó a emitir avisos de seguridad sobre la cadena de suministro de extensiones de IA para programar.

Si usas herramientas de IA para programar, esto te alerta sobre un riesgo real y creciente en la cadena de suministro de software.
